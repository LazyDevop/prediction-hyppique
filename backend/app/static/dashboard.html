Pronostics du jour

Le dernier pronostic enregistré avant le départ de chaque course.

Rejeu a posteriori. Ces pronostics ont été recalculés après les courses, avec des données ingérées avant le départ (historique, terrain mesuré le matin). Utile pour un premier aperçu, mais ce n'est pas une preuve : seuls les pronostics « Avant course », enregistrés avant le départ, en sont une.

Pronostics des utilisateurs de l'app. Envoyés par l'app au moment du calcul et horodatés par le serveur ; seuls ceux reçus avant le départ comptent. Un utilisateur = une installation de l'app (pas encore de comptes).

Calibration

Quand le moteur annonce X % de chances de gagner, le cheval gagne-t-il X % du temps ? Plus les points suivent la diagonale, plus les probabilités sont fiables.

Par type de pari

Un pari est « trouvé » quand l'une des 3 combinaisons proposées par le moteur est gagnante — celles affichées dans l'app. Évalué sur les pronostics enregistrés avec leurs combinaisons.

Utilisateurs de l'app vs moteur automatique

Sur les mêmes courses : le pronostic d'un utilisateur (avec ses saisies et réglages) contre le pronostic automatique enregistré avant le départ. C'est ce qui dit si compléter les données à la main paie.
